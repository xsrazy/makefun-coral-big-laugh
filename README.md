One original funny line about the office printer, 79 characters, that turns on the printer's hopeful name. The program writes the single line to `entry.txt` (UTF-8, no trailing newline).

> I named the office printer 'Hope' because every time I use it, it crushes mine.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`.
